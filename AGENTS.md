# TimeTrap development instructions

- Work on one implementation phase at a time.
- Before editing, restate the phase acceptance criteria.
- Explain every new dependency before adding it.
- Never place secrets or real credentials in repository files.
- Keep the temporal analyzer independent from HTTP and PostgreSQL.
- Prefer standard-library functionality when reasonable.
- Do not refactor unrelated working code.
- Run relevant tests and builds before claiming completion.
- Do not deploy until local verification passes.
- For Zerops work, inspect current services before making changes.
- Never delete or replace a Zerops service without explicit approval.
- End each phase with a "What you should understand" summary.
- Record material AI assistance in the README.
