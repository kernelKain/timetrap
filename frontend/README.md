# TimeTrap frontend

The React, TypeScript, Vite, and Tailwind CSS interface for TimeTrap.

```bash
npm ci
npm run test
npm run lint
npm run build
npm run dev
```

Set `VITE_API_BASE_URL` to the API origin before building. The frontend uses the real persisted scenario and analysis workflow; it does not calculate verdicts or use production result fixtures.

See the repository [README](../README.md), [local development guide](../docs/local-development.md), and [architecture](../docs/architecture.md).
